# Мои ручные действия (практическая работа №1, вариант 01)

1. Открыл консоль облака в браузере.
2. Перешёл в раздел Compute Cloud → Виртуальные машины.
3. Нажал «Создать виртуальную машину».
4. В блоке образа загрузочного диска выбрал Ubuntu 24.04.
5. Указал зону доступности ru-central1-a.
6. В блоке дисков переключил тип на HDD и поставил 15 ГБ.
7. Открыл вкладку «Своя конфигурация», выбрал 2 vCPU, доля 20%, RAM 2 ГБ, прерываемая.
8. В блоке сети оставил подсеть default, публичный IP — Автоматически.
9. В блоке доступа выбрал SSH-ключ, логин student, добавил свой публичный ключ, имя kostin-01-wsl.
10. Выключил резервное копирование.
11. Проверил расчёт стоимости.
12. Нажал «Создать ВМ», дождался статуса RUNNING.
13. Скопировал публичный IP.
14. Подключился по SSH под student.
15. Обновил список пакетов apt update.
16. Установил nginx.
17. Проверил статус nginx — активен.
18. Выполнил set +H.
19. Заменил текст страницы через sed.
20. Обновил страницу в браузере — увидел «labwork on kostin-01-web-manual».
21. Вышел из SSH.
