# hw-01 — стенд домашней работы №1

## Что это

Стенд по заявке заказчика: два веб-сервера за балансировщиком, плюс сервер приложения без публичного адреса.
Все параметры — вариант 01 (Костин).

## Состав

- сеть `kostin-01-net`, подсети `10.11.1.0/24` (зона A) и `10.11.2.0/24` (зона B)
- веб-серверы `kostin-01-web-1` (зона A) и `kostin-01-web-2` (зона B), каждый с публичным адресом
- сервер приложения `kostin-01-app-1` (зона A, без публичного адреса)
- NAT-шлюз `kostin-01-nat` и таблица маршрутизации `kostin-01-rt` — для выхода app-1 в интернет
- балансировщик `kostin-01-lb`, слушает 80, target-port 8003

## Как поднять

./create.sh                    # значения по умолчанию из варианта
./create.sh --web-count 3      # если нужно больше веб-серверов
